# 💸 Antigravity Expense Tracker

A beautiful, interactive, and intelligent personal finance application built using **Python**, **Streamlit**, and **SQLite**. The app features detailed transaction logging, budgeting warnings, savings trackers, professional exports (PDF, CSV), and customized financial advice generated by **Google Gemini**.

---

## ✨ Features

- **🔐 Login & Registration System**: Secure accounts with salted SHA-256 hashed password storage.
- **💸 Expense Manager**: Add daily spending, classify categories (custom and default), filter historical records, and delete expenses.
- **📊 Interactive Charts**: Visual representations of spending splits (Donut charts) and spending habits over time (Trend lines) using Plotly.
- **🚨 Budget Overrun Alerts**: Category budget trackers that issue warning alerts (at 80% used) and alarm alerts (at 100% exceeded) dynamically.
- **🎯 Savings Goals**: Track goals (e.g. Travel, Emergency Fund) with interactive visual progress bars.
- **📑 Professional Exports**: Download your spending logs as filtered CSV worksheets or beautifully formatted PDF financial summaries.
- **🤖 Gemini AI Integration**: Custom AI advisor that analyzes your unique spending profile and outputs personalized money-saving instructions. Includes a live conversational chatbot. (Fallback heuristics handle analysis if no API key is specified).

---

## 🛠️ Tech Stack

- **UI Framework**: Streamlit
- **Data & Charts**: Pandas, Plotly
- **Database**: SQLite3
- **PDF Generation**: ReportLab
- **AI Engine**: Google Generative AI (Gemini 1.5 Flash / 2.5 Flash)

## 🚀 Setup & Launch

1. **Verify Python Installation**:
   Ensure you have Python 3.10+ installed.

2. **Navigate to the Project**:
   ```bash
   cd expense_tracker
   ```

3. **Install Dependencies**:
   ```bash
   pip install -r requirements.txt
   ```

4. **Launch the Application**:
   ```bash
   streamlit run app.py
   ```
   *The app should automatically open in your default browser at `http://localhost:8501`.*

---

## 🔑 Configure Gemini AI

To unlock conversational chat and customized financial reports:
1. Obtain an API Key from [Google AI Studio](https://aistudio.google.com/).
2. Enter the key into the **Gemini Configuration** sidebar within the app.
3. *Alternatively, export the environment variable `GEMINI_API_KEY` prior to launching Streamlit:*
   ```bash
   # Windows PowerShell
   $env:GEMINI_API_KEY="your-api-key-here"
   
   # Linux / macOS
   export GEMINI_API_KEY="your-api-key-here"
   ```
